1. Executive Summary & Syllabus Alignment

Problem Statement: Financial markets generate vast amounts of structured price/volume series alongside unstructured news streams. Conventional dashboards only display raw prices without correlating sudden price collapses, volatility spikes, and news sentiment. This system detects equity anomalies in real time, correlates them with historical market events, and enables semantic search over financial news using vector embeddings.

Level 3 Rubric Compliance: Per syllabus guidelines, "Projects should be completed as 2 member teams. Each team member must have clearly defined responsibilities and contribute to both database and application development. The project should go beyond basic CRUD." Both members have an exact 50% split across database logic, Next.js routes, UI components, and evaluation requirements.

4. Detailed Technical Specifications of Key Programs

A. Market Data Pipeline & Anomaly Engine (Aman Raj - PES2UG24CS053)

  • scripts/seed_market_data.py: Populates reference tables (sector, company, exchange, stock, trading_day). Generates 1 year of daily OHLCV records for 20 equities. Injects synthetic anomalies: flash crashes (sharp 8–15% drops on 4x average volume), speculative spikes, and volatility divergence.
  • database/advanced/01_procedures_functions.sql (Anomaly SP): Defines sp_detect_market_anomalies(p_trade_date DATE, p_std_dev_threshold NUMERIC). Uses PostgreSQL analytical window functions: AVG(close_price) OVER (PARTITION BY stock_id ORDER BY trade_date ROWS BETWEEN 20 PRECEDING AND 1 PRECEDING). Computes rolling Z-scores for price and volume; if deviations surpass the threshold, inserts rows into anomaly and records indicator metrics into anomaly_indicator_value.
  • database/advanced/03_views.sql: vw_stock_daily_stats (calculates 20-day SMA, daily return %, intraday spread) and vw_market_overview (sector-level market capitalization turnover and open anomaly counts).
  • database/advanced/04_evaluation_queries.sql: Fully satisfies Level 3 evaluation queries: JOINs across 4 tables, GROUP BY sector with HAVING clause filtering for average anomaly scores, correlated subqueries identifying decoupling stocks, and ACID transaction blocks with ROLLBACK safety.

B. Semantic Vector Search, Triggers & Auth (Amrit Raj Anmol - PES2UG24CS056)

  • scripts/seed_news_embeddings.py: Seeds realistic market articles (macro rate hikes, bank run liquidity scares, tech earnings beats). Encodes text into 384-dimensional dense vectors using the pretrained all-MiniLM-L6-v2 model. Stores vectors in news_article.embedding and links articles to market_event.
  • database/advanced/01_procedures_functions.sql (Vector SP): Defines fn_match_news_semantic(p_query_vector VECTOR(384), p_threshold NUMERIC, p_limit INT). Leverages the HNSW cosine index (embedding vector_cosine_ops) using the cosine distance operator news_article.embedding <=> p_query_vector to perform sub-millisecond similarity matching.
  • database/advanced/02_triggers.sql: Defines trg_on_anomaly_create_alert (an AFTER INSERT ON anomaly trigger). Whenever an anomaly is logged, it scans watchlist_item for users monitoring that stock and automatically creates personalized unread entries in alert.
  • src/lib/auth.ts & API: Implements secure password hashing with bcryptjs, generates signed JWT session tokens, and enforces role-based access control (differentiating Admin vs. Analyst).
